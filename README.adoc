=== Die Aufgabe: Moviesuche/VideoPlayer mittels TMDB API

Entwerfen und implementieren Sie einen Moviesuche/VideoPlayer für TMDB als native Android App.

Es handelt sich um eine Einzelarbeit. Sich gegenseitig zu unterstützen ist durchaus erwünscht (am besten via Posting in Teams). Falls einzelne Funktionen gemeinsam entwickelt werden, ist dies im Code entsprechend zu markieren. Ansonsten wird es als Plagiat gewertet.

Die im Unterricht gezeigte App ist nur eine mögliche Umsetzung des gewünschten Funktionsumfangs. Sie können dieses UI übernehmen oder aber einen eigenen Entwurf, beispielsweise wie im Modul uidC erarbeitet, umsetzen.

Die Verwendung von KI ist erlaubt, generierter Code muss aber verstanden und erklärt werden können.

Anforderungen:

* Gewünschte Funktionalität
** Suche nach Filmtitel, nach Schauspieler*in, Anzeige der Resultate und Verwalten von Lieblings-Filmen.
*** Anzeige der Liste von gefundenen Filmen
*** Anzeige der Liste der gefundenen Personen
*** Anzeige und Abspielmöglichkeit des Trailers eines Films
*** Anzeige der Liste von Lieblings-Filme
** Abspielen, Pausieren von Trailern eines Films.
* Verwendung der TMDB-API
** https://developers.themoviedb.org
* Das UI ist komplett mit Jetpack Compose zu implementieren.
** https://developer.android.com/jetpack/compose
* Implementierungssprache für die gesamte Applikation ist Kotlin.
* Die im Unterricht erarbeitete Grundstruktur einer Android-App ist anzuwenden. Strukturierung der App in die 3 Layer.
* UI Code ist klar strukturiert in unabhängige Screens und via Composable Functions.
* Das TMDB-Logo soll an prominenter Stelle sichtbar sein (Vorgabe aus den Lizenzbedingungen)
** https://developer.themoviedb.org/docs/faq#what-are-the-attribution-requirements
* Das UI soll verständlich und ordentlich aussehen (keine Minimallösungen mit offensichtlichen Flaws)
* Das UX soll intuitiv also selbsterklärend funktionieren.
* TestCases für ViewModels, Data Klassen und Services
* Weitere Libraries als die, die im Unterricht verwendet wurden, sind nicht erlaubt. Falls Sie zusätzliche Libraries verwenden möchten, um zusätzliche Funktionalität einzubauen, ist dies erlaubt.
